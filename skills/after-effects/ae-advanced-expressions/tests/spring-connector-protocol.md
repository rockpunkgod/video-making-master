# 水平弹簧验证

1. 基线必须保持课程22:25最终表达式：角速度6、振幅100、0–2秒线性归零；前段常幅3/60另作教学阶段。核对源片和真实动画，不用暂停图替代。
2. 新目录构建、实际AE执行、保存重开，移动A并验证B及连接端点传播，恢复后保存重开。脏工程或未归属工程保留。
3. 实际aerender输出TIFF并编码视频；全帧解码检查画幅、帧率、时长、运动。按spring-quality.json核对每帧B的独立像素轨迹，容差固定1.5设计像素；原生等式容差0.001。
4. 变角速度、振幅、归零时间和时长。至少三个新连接图形，以及一个调用者PNG输入；宽度来自真实PNG。逐例检查透明度、媒体存在、正缩放、错误表达式。
5. 看全部10张原生检查PNG，区分过程伸缩与归零后的预期停留。精确对照源片未同步时明确说明。
6. 负例：冻结原生首帧成视频，必须被轨迹检查拒绝；在独立原生副本中漏乘100，必须测得连接错误。失败大文件可在发布后删除，真实JSON回执保留。
7. 审计每个AEP的媒体依赖，入库并核验远端后按交付清单清理。技术结果与人工整体效果分别记录；无后者时candidate。
