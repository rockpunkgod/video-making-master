# 第22节验证

基础：sine/sum/product/decay各实际构建并渲染250帧；slider使用明确标注的推算Profile250帧。不是字幕推断：18全局、57技术Watch图实际查看，包含末尾滑杆8图和乘法间隔8图，公式以画面最终状态为准。完整394条本机ASR仅辅助说明。

泛化：三幅自制暗底PNG，各用sum实际制作250帧；独立复制Skill后以8秒、5弧度/秒、140幅度、80水平速度和PNG实际制作200帧decay。输入边界不能扩展到这些案例之外。

每例保存重开、改BrushSize到3再恢复2、检查每帧原生表达式、5个实际PNG检查点，以及Write-on真实开/关对照。全帧解码，独立公式采样24个历史时间点，沿实际笔刷间隔范围检查5×5像素白笔迹；可见点至少87.5%保留。检查点视频/原生RGB均差<2；PNG输入最大RGB96与白轨迹阈值145分开。读回结构、效果参数和媒体依赖。

负例用真实product电影误配sum请求，以及循环最终原生PNG生成的冻结影片，均必须被独立像素检查拒绝；后者只为FFmpeg负例，不记录为Adobe执行。客观通过不等于课程审美通过；源UI刷新滞后、slider键值推算及正方形像素身份边界保留。
