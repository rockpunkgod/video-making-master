# 第35节实际制作测试

基础：按源length/linear分别制作Scale250→70与FastBlur40→0，两者距离半径70，原生目标属性零关键帧。控制器使用明确测量重放，不能宣称源运动关键帧。

泛化：数字、几何、箭头三组新PNG各走两个分支。独立复制Skill，在实验室外cwd用sub/length、8秒、半径55、模糊32和镜像Profile制作；不是导入实验室内部工具。

原生：保存重开、实际位置编辑联动、恢复重开；所有帧核对控制器线性插值和欧氏距离、二维无父级、Fast Blur名称/Horizontal&Vertical/RepeatEdges0。每例五原生时点和两个开关图实际审阅。

电影：完整解码与每帧独立像素检测；Scale32边界点、5×5窗口、排除控制器半径23，至少90%支持；Blur每个目标高模糊与零模糊至少2帧，排除控制器圆区后的平均梯度比<0.85。对应原生五帧RGB均差<2；开关均差>0.1。记录测量边界，不能拿指标替代审美。

负例：冻结原生PNG视频、真正原生不同分支电影误配，保持相同尺寸帧率时长；必须被实际内容检查拒绝。源左右对照、参数推定和反馈绑定具体SHA，未确认的总体效果保持candidate。
