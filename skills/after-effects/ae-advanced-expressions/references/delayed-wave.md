# 递归延迟的三维波浪阵列

来源：[第34节波浪起伏](https://www.bilibili.com/video/BV1c7GTzMEh5/?p=34)。这是前一图层Position的时间采样链，与第21节空间布局、第22节三角函数共享原理；不能把它变成Write-on笔迹，也不能把递归属性读取替换成自主平滑或弹簧。

## 课程原法与执行

先以具有NumPy/Pillow的既有Python调用scripts/build_delayed_wave.py --out全新目录，再使用本Skill的run_ae.py、render_ae.py实际执行AfterFX/aerender。只串行运行Adobe任务。原生AEP、电影、请求/计划、原生回执、像素检查和9张必要PNG是交付物；生成脚本副本、渲染序列与隔离复制目录在出版及媒体依赖审计后清理。

00:45–00:50源对话框：720×576，PAL/DV、25fps、10秒。像素比例UI显示1.09、画面比例160:117，由此采用128/117，实际AE读回确认；MP4也写入128:117 SAR。原课预览没有开启像素比例校正，左右评审对照按原预览720:576归一，不能把对照的SAR1当成工程PAR1。

01:00–01:25创建满画幅红Solid a，解锁统一缩放后X=1%、Y=80%，然后开启3D。实际图层仍720×576、Anchor360/288，不能换成独立7.2×460.8矩形并假装同一图层结构。

第一层原式：

```javascript
fudu=40;
pinlv=3;
z=fudu*Math.cos(pinlv*time);
value+[0,0,z]
```

课程先用50幅度，11:30后改40。频率直接乘时间得到弧度，不补2π。value保留调用者的可编辑基础位置。下一层duplicate后移到第一层下方，原式为：

```javascript
thisComp.layer(index-1).position.valueAtTime(time-.2)+[10,0,0]
```

08:15–08:35书写与口述确认0.2秒，不是2秒；09:55后先加13水平偏移，12:35试6，13:00恢复10。复制的是带递归表达式的第二层，第一层始终索引1；摄影机必须在条形层下面。14:00先试100-index*3，14:35改成100-(index-1)*3，使第二层97%，后续逐层减3。第一层本身100%。当前默认23条，源15:45的Null24/Camera25及条形23可读；最初预览Comp1的32条和0.1延迟是另一演示状态，不混入Comp2基线。

--mode controller在底部禁用Null 1上建立三个Slider，名fudu/pinlv/jianju。首层幅度/角速度读前两个；所有后继层的水平偏移读jianju。当前复刻36、3.53、21是18:15/20:15后画面值；最终控制器场景复制总数未独立读回，沿用23条且保留裁切边界，不冒称原工程身份。课程18:35–19:35特意指出只改第二层、旧副本仍常量10的问题，删除旧副本再复制；当前确保所有后继层均绑定，不复刻这个临时错误作为最终状态。

08:55摄影机创建框明确开启景深、Lock to Zoom、光圈5.00mm、Blur100%；当时Zoom/Focus460.96mm。实际AE26本机Camera Settings以毫米输入5，保存后属性读回14.1732283464567px，实测对应5×72/25.4；不得误填5px。工程保留景深，Focus Distance用cameraOption.zoom表达式保持相等，Blur100。最终摄影机变换后Zoom未展开，当前Focus跟随推定Zoom1351.3897px，并不冒称原片最终焦距数值。原生景深开/关各导出PNG，检查真实图像差异；当前光圈下柔化较轻，不为追求明显模糊擅自增大光圈。Adobe参数含义参见[官方说明](https://helpx.adobe.com/after-effects/desktop/work-with-layers/camera-layer/cameras-lights-points-interest.html)。

摄影机最终完整属性没有展开。本例用13:15和14:15两个时刻的8个端点，加原片15:45的5个其他条形端点，共13个观测估计静态机位/Zoom；另留源15:45、合成7.88秒的首条底端作检查。实际宿主确认PAL投影须同时按PAR缩放世界X与摄影机方向，不能套正方形针孔模型，不能声称精确源摄影机；真实原生投影误差和留出点记录在每例delayed-wave-quality的source_camera_measurement。不可为了得到较低拟合误差伪造原片读数。

## 输入、变化与组合

--mode fixed|controller；--count2..30；--duration4..12且整25fps帧；--amplitude绝对值5..60，可负；--rate0.2..6；--spacing绝对值4..24，可负；--delay0.05..0.4。这是接口允许边界，实测用例见结果，不能视作所有组合已验。不自动重构摄影机或把出画元素挪回。

--asset为调用者自有、不透明720×576PNG，每像素至少一个通道≥150，按原满画幅图层再缩放1/80。复制到输出assets，明确解释为PAL128/117。当前只验证三种自制亮色纵向纹理；没有测试任意透明PNG、任意尺寸、影片、文字和跨素材相机自动匹配。--camera可传显式新估计参数；p34-camera-mirrored.json是负间距的自制镜像视角变体，不能当原课摄影机。

静态控制下独立校验式为x=baseX+(index-1)*spacing，z=A*cos(w*(time-(index-1)*delay))。这只是验证器，不替换工程中的递归原式。负时间继续采样cos，不能clamp到零或使用画面第一帧代替。若将来给滑杆K帧，递归链会在不同时刻读取先前参数；当前只支持恒定滑杆，不声称已验证动态滑杆历史传播。

## 诊断与验证边界

只沿Z运动且正面摄影机时视觉像缩放；先核对3D开关和摄影机，再调视角。index表达式报错时查首层/摄影机/Null顺序；不能把摄影机加到索引1。改滑杆只动一段时检查每个副本表达式，按课程删除旧副本重建。小间距可能重叠，负间距向左延伸；不要静默自动居中。颜色/PNG变形查图层Footage与Comp的PAR，电影播放比例再查SAR。

宿主有未保存或非实验工程时停止并保留。重开后重新找Comp/Layer，不复用失效引用。递归层数过高可能变慢，本候选限制30条；失败输出保持失败，不能用纯Python动画代替原生成功。

每例实际保存重开、修改基础X或Slider幅度并确认末层响应后恢复；250/200帧真实坐标和透明度逐帧核对。使用实际AE toComp点建立投影矩阵，训练/留出分开，再检查整部电影每条5个中心线像素点。投影校准来自当前工程，不证明源摄影机身份；重叠条可能共享像素支持。审美与课程对齐须另看真实左右对照和人工反馈。详见../tests/delayed-wave-results.json。
