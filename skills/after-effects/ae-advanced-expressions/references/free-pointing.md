# 自由指向：课程第33节

来源：https://www.bilibili.com/video/BV1c7GTzMEh5/?p=33 。candidate；不能把技术检查当作原素材/原时间轴一致。

## 原法与两种偏移

07:48完成核心表达式；08:28/08:42字母最终减90；11:45/13:50横线最终不加偏移：

```javascript
point1=transform.position;
point2=thisComp.layer("目标").transform.position;
chazhi=sub(point1,point2);
angle=Math.atan2(chazhi[1],chazhi[0]);
radiansToDegrees(angle); // 字母末尾为 radiansToDegrees(angle)-90;
```

保留point1减point2、atan2先Y后X及弧度转角度。不要换lookAt、路径朝向、平滑角度或另一套惯性模板。早期拼写错误及加90的尝试不是最终表达式。第一例同时演示移动目标与字母自身，不能只读取目标绝对坐标。

09:14直接可见第二例位置表达式，随后复制为25层；14:00/14:20核对最终：

```javascript
row=Math.ceil(index/5);
column=index-(row-1)*5;
x=column*64-32;
y=row*48-24;
[x,y]
```

条层占index1..25，目标在其后。改变层序会改变阵列位置。当前脚本使用原生duplicate，不用手写25个固定坐标替代index。

## 执行和输入

调用scripts/build_free_pointing.py --mode grid或letter --out <全新目录>，同目录run_ae.py <build.jsx> --ae <AfterFX.exe>，然后render_ae.py <目录> --aerender <aerender.exe> --reuse。当前已实测宿主AE26.0x67。制作期间不要同时打开其他工程；有未保存或非本实验工程时保留现场并停止。

--profile默认读取examples/p33-grid-replay.json或p33-letter-replay.json。JSON包含duration和严格递增keyframes；每点有time、target二维坐标，letter还需follower坐标。4..12秒、30fps完整帧（本轮原生实测均6秒，其他时长未原生实测）；grid固定320×240、letter160×120，坐标在画布内。交付640×480是自制显示包装；内层工程坐标仍可编辑。

源片是固定合成时间下手动拖动，不是作者给出的时间轴动画。两个示例分别从13:30–13:36、08:28–08:34测量可见圆心；每段150帧中138/120帧接受，重影或遮挡的12/30帧排除，在接受点之间自制线性重放。圆心不等同于已恢复的源锚点；精确刷新时序、空间轨迹插值和原工程键值未验证。源第一例160×120、第二例320×240及30fps由位置/预览比例推定，未见本节合成设置对话框；6秒为重放时长。不要把这些推定包装成课程明示参数。

原a.ai未获取；当前自制黑圆/灰边/ArialMT字母a。背景RGB近似，目标尺寸重建；Info显示255/255/153和Alpha77，使用图层Opacity30是本实现选择，源透明度设置位置未读出。输出包装及嵌套字母连续栅格化为清晰交付适配。无原素材身份或像素级一致性声明。

--asset接受自有透明PNG，复制到assets，必须显式--offset。当前像素检测适配器支持亮黄/白、细长且不超中心圆形边界的图形，16..2048像素，覆盖度及主轴可测；暗色/圆形素材不在已验范围。--columns2..7、--rows2..5改变阵列数量与半格间距；--mirror-x镜像重放轨迹。这些都是明确泛化，不是原课5×5基线。

方向偏移由素材自身朝向决定。公式先得到“目标到自己”的角度；素材朝上用−90，朝右用180，朝下用90，朝左用0。横线无箭头，0与180的轴线相同；不能用无向主轴检测声称已验证任意箭头头部。自制三个朝上PNG用−90，亦已检查实际画面。

## 验证和诊断

每帧原生公式/位置与真正影片像素都检查。线条/细长PNG以主轴核对模180度方向；原生零旋转字形导出用于完整有向字形轮廓核对，避免小写a主轴弱而误报。冻结旋转但位置仍动的错误影片由Adobe真实制作，检测器已拒绝。保存重开、目标位移编辑联动、效果开关像素变化及依赖审计另留证据，不能由脚本生成成功替代。

关键帧时间在本机量化到1/1024帧；全片重放坐标误差单独记录，不把量化误差冒充来源误差。原法Rotation无自制关键帧；重放关键帧只用于位置输入。

仅支持同一合成的未父级化二维图层。父级/三维空间不能直接相减本地Position；本单元不擅加未验证坐标变换。四象限及目标重合已原生测试：重合时atan2(0,0)返回0，方向物理上不唯一；保留课程结果，不偷偷添加保持角度或缓动修复。±180角度换号本身不等于方向跳变，先核对画面，再判断问题。

重现时使用全新输出目录。入库后临时渲染已删，不能把已清理的帧序列回执当作仍可打包的视频输入；重新制作或在AE中选新的渲染输出位置。跨机器重建，或重链接随附assets。人工反馈绑定具体成片SHA和范围，详见tests/free-pointing-results.json。
