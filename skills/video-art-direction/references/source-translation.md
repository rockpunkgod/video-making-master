# 来源、固定版本与视频化改造

直接阅读的来源是[Distinctive AI Design](https://github.com/houxin0010/distinctive-ai-design/tree/92c68366767b98924fe2719c16659e7f1e93c7af)，固定提交92c68366767b98924fe2719c16659e7f1e93c7af，读取日期2026-11-07。已读README.md、SKILL.md、references/review-and-media.md和docs/VALIDATION_RESULTS.md，未执行其安装、测试或页面脚本。

| 来源思路 | 视频中的改造 | 必须留下的依据 |
| --- | --- | --- |
| 多方向视觉概念 | 2–3种叙事视点、空间或镜头/节奏结构 | 能说清镜头表现与舍弃内容的差异，非换肤 |
| 具体创意Brief | 增加情绪弧线、镜头动机、运动规则、阅读/停留时间与声画关系 | 每个美术选择服务何种表达 |
| 真实随机种子 | 卡住时扰动空间、节奏、构图的探索线索 | 本机种子、锁定约束与提案；不输出到产品 |
| 独立截图评审 | **独立连续成片播放和实际试听**；截图仅辅助 | 影片SHA、时间段、速度、评审身份与可感知观察 |
| 按需生成媒体 | 使用已有素材/原生AE/PR；新媒体仅在承担叙事时引入 | 素材角色、声音角色和实际可用性 |
| 删除无用元素 | 减镜头、转场、强调、特效与无功能停顿，同时保护信息/呼吸 | 删除项、表达收益、可能损失与替代办法 |
| 最多两轮、抓主要问题 | 默认两轮，每轮1–3个最高影响修正 | 同框架复看复听、剩余缺口与停止理由 |

入口“设计不只是加法”和六项视频用法来自本次用户明确要求。连续运动/声音硬门槛、镜头与声音计划、文件SHA绑定和证据状态机是本项目的视频适配，不能归为上游原有视频验收能力。

上游自身的验证报告区分了静态检查与未执行的设计/独立评审；本项目也不把结构测试或合成测试记录冒充真实艺术评审。上游提及Lenny’s Newsletter文章是其二手来源，本次没有重读该文章正文，更不补全未公开的付费内容。

本Skill独立编写中文视频流程与本地检查工具，未复制上游完整文件、安装原Skill或改动上游仓库。它作为Video Making Master交付中的艺术指导层，通过Brief/镜头/声音计划衔接现有制作能力；不读取或耦合其他VideoMaking仓库内部实现。
