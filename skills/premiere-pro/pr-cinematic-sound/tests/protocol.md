# 验收

1. 基础原生制作：三画面、八音轨、独立音量包络、真实可播放成片及PR工程。
2. 变参：改变对白、环境/音乐源、镜头顺序和转场时刻，不能依赖固定时间点或单个音效。
3. 至少三组不同声音素材与事件配置；按新计划生成原生关键帧和编辑工程。
4. 技术：原生字段/关键帧读回、实际工程重开与参数编辑；全帧解码；独立PCM参考对齐≤1ms，参考SNR≥22dB，100ms窗口音量误差≤1dB，峰值≤-1dBTP。响度观察范围-35至-10LUFS只检测静音/过响，不是交付标准。
5. 视觉与听感：检查切点、声效因果关系、对白清晰、底噪、转场和整体层次。用户已指出首版持续底噪，须修复并重新试听，不得忽略。

无音频输入能力时明确缺口，不能声称已经听音；保留用户反馈与修订记录。所有门槛完成前candidate。
